# ASS MAGIC original player candidates

The five `.glb` files in this directory are generated by
`generate-original-player-models.mjs`.

- Geometry is created from original authored proportions and procedural
  primitives in this repository.
- No geometry, topology, texture, logo, material, animation, or other model data
  from `cesium-man.glb` is copied into these files.
- No external model, paid asset, stock texture, brand mark, or third-party
  character design is used.
- The current player was referenced only for numeric compatibility targets:
  approximate height, fingertip span, shoulder position, and ground position.
- The generated model data is intended for ASS MAGIC use without third-party
  model attribution.

The models are lightweight articulated-part prototypes in a T-pose. They are not
yet skinned to a production skeleton. Production skinning, weight painting, and
flight-pose validation should be performed only after a candidate is selected.
